# 1.区域赋能项目前后端全栈
把离散的**业务事件**（闲置/寻物/急救/讨论 + POI 语义）按「业务量均衡 + 服务半径最短 + 形状紧凑」智能聚成若干**服务片区**，并用 Voronoi 边界落地到地图。  
技术栈：React 18 + Vite + 高德 JSAPI 2.0（前端） / FastAPI + SQLAlchemy 2 + Pydantic v2（后端） / PostgreSQL 13 + PostGIS 3.2（生产数据） / numpy + shapely（算法）。
项目思路：该项目从最开始的比赛项目到一步步进化成完整的可使用的区域赋能项目，非常扎眼的使用了GIS元素，以及GIS的部分理念。当我还是一个GISer时，我当时将很多的精力放到了GIS生活化这个方面，很多ToC的应用是可以通过GIS技术在视觉显示和交互上是更胜一筹的。虽然GIS作为一个备考地理大树的一个工具，更多的被用在区域监测、自然灾害预测监测等方面，但是也许换条路他也能大放异彩。在学习GIS的一路上，碰到很多优秀的同行，一路的感动和震撼都是我人生路上难以忘怀的，
