③ 简历亮点

  • 完整闭环：数据生成 → 空间算法 → PostGIS 持久化 → 高德可视化 → 参数市场（调参/保存/对比/分享链接）→ 测试与文档。
  • 生产级几何：片区边界由 PostGIS ST_VoronoiPolygons 生成，并 ST_Intersection 裁剪到真实北京行政区，而非简单外接框。
  • 容量约束聚类：k-means++ 初始化 + 容量约束 Lloyd 迭代 + move/swap 局部搜索，目标函数兼顾服务半径、业务量均衡与形状紧凑度。
  • 工程化：FastAPI + SQLAlchemy 2 + Pydantic v2；pytest 14 用例（含真实 PostGIS 集成测试）；无库时自动回退文件模式。
  • 可分享方案：参数（K/λ/μ/seed/类型）编码进 URL，跨用户无需登录即可还原方案并一键应用到大图。

④ 本地运行

后端 cd api && .venv/Scripts/python -m uvicorn app.main:app --port 8000 · 前端 cd frontend && npm run dev（http://localhost:3000）。
灌库：python -m scripts.seed → python -m scripts.load_beijing_districts。
换真实行政区边界：把 DataV 110000_full.json 存为 data/beijing_districts.json 后重跑上面第二条命令即可。
